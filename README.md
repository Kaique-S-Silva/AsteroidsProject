# Asteroids Clone

A simple Asteroids-style arcade game built to practice game loops, collision detection, and basic rendering.


## Features
- Player ship movement and shooting
- Asteroid spawning and splitting
- Collision detection and game over state

## Tech Stack
- Language: Python
- Libraries: pygame
- Tools: Git, GitHub

## Getting Started

### Prerequisites
- Python 3.10+
- pip
- pygame

### Installation
```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
pip install -r requirements.txt
```

### Run
> python main.py

### Controls
- Move: Arrow keys / WASD
- Shoot: Space
- Quit: Esc
